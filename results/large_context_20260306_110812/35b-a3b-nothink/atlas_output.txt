IDENTITY: This project is a scroll-driven marketing site for DebateHaus that orchestrates immersive animations and conversion flows using GSAP and React.
STACK: TypeScript, Next.js, React, GSAP, ScrollTrigger, Tailwind CSS, PostCSS, Autoprefixer, ESLint, SWC, JSON.
ARCHITECTURE: The system separates presentation, configuration, documentation, and infrastructure layers. The presentation layer contains src/hooks/useGSAP.ts and src/components/EnhancedHero.tsx which drive the visual experience. Configuration files like tsconfig.json and .eslintrc.json enforce type safety and code quality. Documentation in docs/DesignPlan/1-hero.md guides implementation. The global layout in src/app/layout.tsx integrates these layers.
SUBSYSTEMS: Ui (Src) #2: src/components/PercentageBasedTrustSection.tsx, src/components/PercentageBasedRoadmapSection.tsx
DebateHaus Marketing Landing Pages: src/components/BetaSignupForm.tsx, src/components/CanvasBackground.tsx
Ui (Docs) #3: docs/DesignPlan/1-hero.md
Ui (Public): src/data/copy.json
Ui Marketing Content Gateway: src/types/marketingContent.ts
Ui (.): src/tailwind.config.ts
Ui Build Configuration: next.config.js
Beta Signup Form: src/components/BetaSignupForm.tsx
FLOW: User interaction triggers GSAP ScrollTrigger instances in src/hooks/useGSAP.ts. This updates state managed by src/components/EnhancedHero.tsx. Content is fetched synchronously from src/data/copy.json via src/types/marketingContent.ts. The BetaSignupForm component handles user input and submits to simulated endpoints.
PATTERNS: The system uses custom hooks for animation state and a centralized JSON asset for content localization. Global styles are defined in src/app/globals.css and src/app/layout.tsx.
RISKS: Legacy files with outdated naming conventions (_OLD, _BAD) are actively exported in Ui (Src) #2. Production debug logging exists in the Trust section. ScrollTrigger cleanup relies on iteration rather than instance storage. Global animation state uses mutable singletons instead of React Context. Beta Signup Form uses setTimeout for simulated API calls and contains hardcoded animation timing. Documentation debt exists in Ui (Docs) #4 with chronological regressions.
