IDENTITY: This project is a comprehensive codebase for the CoDRAG system, integrating AI-driven code analysis, SQLModel database operations, and a multi-platform user interface with extensive testing infrastructure.
STACK: The codebase utilizes Python for SQLModel and FastAPI backend logic, TypeScript and React for web UI components, Rust for CLI tools and code analysis engines, Kotlin and Java for networking libraries like OkHttp, and Go for web frameworks. Build tools include Vite, Maven, Gradle, and GitHub Actions for CI/CD.
ARCHITECTURE: The system is organized into layers including testing, documentation, business_logic, presentation, infrastructure, configuration, build, and data. The presentation layer relies heavily on TEST2/website.clean/app/download/page.tsx and TEST2/website.clean/app/layout.tsx as central hubs. The business_logic layer connects SQLModel Database Integration with Testing Infrastructure for SQLModel. The infrastructure layer supports networking via OkHttp and Alamofire implementations.

FLOW: Requests enter through TEST2/website.clean/app/layout.tsx which routes to specific pages like TEST2/website.clean/app/download/page.tsx. Data persistence flows through SQLModel Database Integration using session management. CLI tools like bat and ripgrep process text via Rust implementations. Real-time updates use WebSockets managed by UI Communication and Real-Time Networking.
PATTERNS: Shared dependencies include website-ui, website-legal, and legal-docs across most subsystems. Error handling is standardized in UI Error Handling and Exception Management. Testing is pervasive with dedicated subsystems for mocking and validation.
