IDENTITY: Halley Core is a local-first AI persona system managing autonomous agent cognition, memory persistence, and multimodal roleplay interactions through a hybrid Rust-Tauri desktop and Python-React architecture.
STACK: Python, TypeScript, React, Tauri, Rust, Tailwind CSS, Radix UI, Ollama, ComfyUI, Diffusers, RunPod CLI.
ARCHITECTURE: The system follows a layered architecture with business logic in Python and TypeScript, presentation in React, and infrastructure in Rust and Python. The halley_core/api/app.py serves as the central API gateway connecting frontend components like halley_core/frontend/vite.config.ts to backend services. The architecture separates concerns into persona management, memory systems, and inference orchestration, with the halley_core/frontend directory housing UI primitives and the halley_core/api directory managing LLM providers.

FLOW: User interaction begins at halley_core/frontend/index.tsx or halley_helper/frontend/index.tsx, routing through halley_core/frontend/App.tsx to the chat interface. Requests pass to halley_core/api/app.py, which routes to specific subsystems like halley_core/core/persona.py for persona logic or halley_core/ollama/provider.py for inference. Data flows to halley_core/memory/v2_system.py for storage, then to halley_core/resources/gpu_monitor.py for resource allocation. Responses return via halley_core/api/app.py to the frontend, with error handling managed by halley_core/resilience/error.py.
PATTERNS: The system uses a provider pattern for AI models (halley_core/llm/adapter.py, halley_core/media/providers.py) and a facade pattern for image generation (halley_core/images/generation.py). Dependency injection is used for tool registration (halley_core/tools/registry.py). Error handling follows a centralized resilience model (halley_core/resilience/error.py) with circuit breakers.
RISKS: Test scripts in Halley Core Persona & Memory System contain hardcoded absolute paths and magic numbers. Roleplay Data & Persona Management has hardcoded polling intervals and inconsistent error handling. Roleplay (Halley Core) #13 relies on placeholder JSX for UI migration. Halley Core Resource & Task Orchestration has incomplete ComfyUI and AMD GPU support. PuLID Identity-Preserving Generation has hardcoded paths and brittle state parsing. Roleplay (Halley Core) #9 has unimplemented CoreML and Mochi backends. Roleplay Narrative Engine relies on silent fallbacks for missing libraries. Roleplay (Halley Core) #48 lacks robust model metadata retrieval. Roleplay (Halley Core) #15 has WebSocket reconnection limitations. Roleplay (Halley Core) #14 has deprecated legacy modules. Roleplay (Halley Core) #55 has incomplete regeneration logic. Roleplay (Scripts) #2 has hardcoded server IPs and security risks. Roleplay (.) #4 has unresolved legacy references and missing testing.
