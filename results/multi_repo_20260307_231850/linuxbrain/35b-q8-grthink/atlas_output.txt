IDENTITY: Halley is a local-first AI persona system that orchestrates autonomous cognitive agents with persistent memory, emotional modeling, and multimodal generation capabilities through a hybrid desktop and web architecture.
STACK: Python 3.8+ for backend logic and inference, TypeScript/React for frontend interfaces, Rust for Tauri desktop packaging, Node.js with Vite for build tooling, and Tailwind CSS for styling.
ARCHITECTURE: The system follows a layered architecture with infrastructure handling GPU orchestration and API adapters, business logic managing cognitive states and memory, and presentation layers for chat and settings. The halley_core/api/app.py serves as the central Flask entry point connecting to the frontend via the halley_core/frontend directory. The Rust backend halley_helper/src/main.rs bridges Tauri IPC to the Python services. Data flows from the frontend components through the API layer to the inference engines like Ollama or ComfyUI.

FLOW: User interaction begins in halley_core/frontend/App.tsx or halley_helper/frontend/main.tsx. The frontend calls halley_core/api/app.py endpoints which route to specific business logic modules like halley_core/cognition/core.py or halley_core/memory/v2/core.py. For media tasks, requests flow to halley_core/api/comfyui_client.py or halley_core/api/wan_video.py. The Rust backend halley_helper/src/main.rs manages system tray and IPC, delegating GPU tasks to halley_core/api/gpu_monitor.py. Observability data is logged via halley_core/observability/logger.py and metrics are tracked in halley_core/api/metrics_store.py.
PATTERNS: The system uses a Provider pattern for AI inference (halley_core/api/ollama_provider.py, halley_core/api/comfyui_client.py) and a Factory pattern for model initialization (halley_core/api/provider_factory.py). Error handling is centralized in halley_core/api/error_handler.py with a declarative taxonomy. Dependency injection is used for tool registration via halley_core/api/tool_registry.py. Lazy loading resolves circular dependencies in halley_core/core/orchestration.py.
