IDENTITY: Halley Core is a local-first AI persona system that orchestrates autonomous cognitive agents with persistent memory, emotional modeling, and multimodal generation capabilities via a desktop application and backend services.

STACK: Python 3.8+ with FastAPI and Flask backends, React with TypeScript and Tailwind CSS frontend, Rust via Tauri for desktop packaging, Ollama for local LLM inference, ComfyUI for image generation, Wan 2.x and Mochi for video synthesis, and PyTorch with Diffusers for deep learning.

ARCHITECTURE: The system follows a layered architecture with business logic in Python modules, presentation in React components, and infrastructure in Rust and shell scripts. The halley_core/api/app.py serves as the central API gateway connecting to the backend Flask and FastAPI services. The frontend entry points in halley_core/frontend/src/index.tsx and halley_core/frontend/src/main.tsx mount the React root containers. The halley_core/frontend/vite.config.ts orchestrates the build pipeline. Data persistence relies on JSONL and JSON formats managed by the Roleplay Data & Persona Management subsystem. The halley_core/api/app.py routes requests to specific subsystems like the Roleplay Subsystem (Halley Core) #2 for chat orchestration and Roleplay (Halley Core) #34 for UI state management. The Halley Helper Desktop Application uses Tauri to bridge the Rust backend with the React frontend, managing system tray interactions and IPC.

FLOW: User interaction begins at the frontend entry point halley_core/frontend/index.tsx, mounting the App component which routes to the chat interface. The UI component TabbedSelector in halley_core/frontend/components/TabbedSelector manages state and sends requests to the API gateway halley_core/api/app.py. The API routes to the Roleplay Subsystem (Halley Core) #2 for chat orchestration, which invokes the Roleplay Core for persona logic. For memory operations, the system calls Roleplay Memory System v2 at halley_core/memory/v2, which triggers the CLaRa Context Compression Subsystem at halley_core/compression/clara for token optimization. Image generation requests flow through the Roleplay Image Generation Subsystem at halley_core/media/image, utilizing the Roleplay Identity Encoder at halley_core/identity/encoder to inject facial embeddings. The backend coordinates with the Halley Core Resource & Task Orchestration at halley_core/resources/gpu to manage VRAM and GPU allocation before executing the generation via ComfyUI or Diffusers.

PATTERNS: The system employs a provider pattern for media generation (halley_core/media/providers) and a facade pattern for persona management (halley_core/persona/generator). Dependency injection is used for LLM adapters (halley_core/api/adapter) and video providers (halley_core/video/providers). Error handling follows a resilience pattern with circuit breakers in halley_core/resilience/errors and automatic recovery strategies. The architecture uses a dual-storage model for personas (halley_core/persistence/personas) separating source files from derived data. Lazy loading is implemented to resolve circular dependencies in the cognitive core (halley_core/cognitive/beliefs).
