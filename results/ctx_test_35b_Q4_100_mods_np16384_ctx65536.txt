IDENTY: This project is a comprehensive codebase for the CoDRAG and Halley applications, providing AI-powered code analysis, RAG search, and marketing UI infrastructure built on SQLModel, FastAPI, and React.
STACK: Languages include TypeScript, Python, Rust, Java, Kotlin, Go, Ruby, and C. Frameworks include FastAPI, SQLModel, SQLAlchemy, Pydantic, React, Next.js, Vite, Storybook, Javalin, Spark, Gin, and Alamofire. Build tools include Maturin, Maven, Gradle, and PostCSS. Runtime environments span web browsers, VS Code extensions, Android, and serverless GPU execution on Google Cloud Run, Modal, and RunPod.
