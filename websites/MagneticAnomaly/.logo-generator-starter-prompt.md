# Starter Prompt: Make /logo-generator live on magneticanomaly.llc

## Goal
Promote the existing local-only `/favicon.html` page into a public, deployed page at `https://magneticanomaly.llc/logo-generator`.

## Background
- `websites/MagneticAnomaly/favicon.html` was created as a stripped-down, no-index render page to screenshot a tiny moon + rainbow particles for favicon assets.
- It currently uses `src/favicon.jsx` and `src/FaviconScene.jsx` / `src/FaviconParticles.jsx`.
- The MagneticAnomaly site is a Vite + React app deployed manually via FTP (`npm run build` + upload `dist/`). See MEMORY.md: "MagneticAnomaly deploy = manual FTP".
- The current page has `<meta name="robots" content="noindex,nofollow,noarchive">`.

## Requirements
1. Make the page routable at `/logo-generator` in the production build.
   - Either rename/route `favicon.html` to `logo-generator/index.html` or create a public entry.
   - Ensure Vite bundles `src/favicon.jsx` and all dependencies correctly.
2. Decide and implement public visibility:
   - Remove the `noindex` robots meta if this is meant to be a public page.
   - Update `<title>` and meta description to reflect it is a logo/favicon generator.
3. Add a link or mention on the main site (optional — confirm with user).
4. Build: run `npm run build` and verify `dist/logo-generator/index.html` exists and works locally via `npm run preview`.
5. Do NOT deploy/FTP unless explicitly asked again — only prepare and verify locally.

## Files likely touched
- `websites/MagneticAnomaly/favicon.html` or new `logo-generator.html`
