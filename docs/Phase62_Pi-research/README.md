## TL;DR

**CoDRAG is Layer 1 (Intelligence).** It doesn't compete with coding agents (Layer 3) or orchestrators (Layer 4). It makes ALL of them better.

```
Layer 4: Paperclip (orchestrator)
Layer 3: Claude Code / Cursor / Antigravity / Pi (agents)
Layer 2: Sequential Thinking / Superpowers (reasoning & workflow)
Layer 1: ★ CoDRAG ★ (codebase intelligence)  ← WE ARE HERE
Layer 0: Ollama / Cloud APIs (models)
```

**Strategy:** Universal access. Don't pick one agent — support them all via MCP (primary), CLI (universal), AGENTS.md (passive), and HTTP API (custom).

**Recommended Configuration Profiles:**
| Profile | Stack | Complexity |
|---|---|---|
| A: Minimal | Built-in ONNX + any agent + CLI | Zero config |
| B: Standard | Ollama + Claude Code/Cursor + MCP | Low |
| C: Power User | Ollama + Claude Code + Sequential Thinking + CoDRAG MCP | Medium |
| D: Enterprise | Paperclip + Claude Code + CoDRAG MCP + Superpowers | High |
| E: Minimalist | Pi + CoDRAG CLI/Skill | Low |
| F: Antigravity | Antigravity + CoDRAG MCP | Low |

**See [06_Ecosystem_And_Configurations.md](./06_Ecosystem_And_Configurations.md) for full details.**

## Key Finding

> CoDRAG's job isn't to pick a winner between Claude Code, Pi, Cursor, or Antigravity. Its job is to make ALL of them smarter by providing codebase intelligence through four universal interfaces: MCP, CLI, HTTP, and AGENTS.md.
