## Purpose

Phase 74 introduces **Concepts** — a new epistemic capability for CoDRAG that captures *conceptual understanding* of a codebase: the "why" behind the code, the business rationale, domain knowledge, design decisions, brand reasoning, and architectural intent that today exist only inside developers' heads.

This is not a 12th pipeline stage. Concepts is a **standalone dashboard panel with its own initialization**, following the pattern established by the Architecture Diagram (Phase 71), Audit, and Opportunities panels.
