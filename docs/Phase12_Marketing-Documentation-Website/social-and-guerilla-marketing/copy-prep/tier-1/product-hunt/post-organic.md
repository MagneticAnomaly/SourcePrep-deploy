## Maker Comment (Organic)

**Headline: "I built this because I was tired of guessing imports."**

Hey everyone! 👋

I'm an engineer who spends way too much time in large codebases.
I love AI tools, but I hate how they "hallucinate" libraries that don't exist, just because they didn't see the import file in their context window.

**CoDRAG** is my attempt to fix that.
It's a local tool that *guarantees* the AI sees the definition of the function you're asking about.

It's not magic. It's just a really robust dependency graph.
But sometimes, a graph is better than magic.

Hope it helps you ship faster. 🚀
