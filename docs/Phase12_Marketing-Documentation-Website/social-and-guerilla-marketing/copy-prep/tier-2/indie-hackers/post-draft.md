## Body Structure

### Hook
Everyone says "make it a subscription." But for a local-first tool where the user provides their own API keys (BYOK) and storage, a monthly fee felt wrong.

### The Product
**Prep** is a local context engine for coding. It runs on the user's machine. Zero cloud costs for me (except the update server).

### The Model
*   **Free Tier:** For hobbyists.
*   **Pro License:** One-time payment ($79). Own it forever.
*   **Team:** Subscription (for the shared policy/sync features).

### Why this works for Indies
*   **Cashflow:** Upfront revenue to fund dev.
*   **Alignment:** No incentive to hoard user data to justify a recurring fee.
*   **Trust:** Developers hate subscriptions for tools that run locally.
