# Prep Marketing Strategy Update (April 2026)

## 1. Core Positioning Pivot
We are transitioning away from leading with "Privacy", "Local-First", and "Zero-Configuration." While these remain functional benefits, they are not the primary reason high-end developers and autonomous agent platforms will adopt Prep. We are assuming elegance and sophistication in our target demographic. 

**The new core narrative:** Prep is the engine that provides **epistemic codebase understanding**. It goes infinitely deeper than naive vector search by parsing the DB, mapping the structural graph (what, why, when, how), and giving agents the contextual self-awareness they lack.

## 2. Hero Proposition
**Headline:** Give your AI the epistemic context to actually understand your code.
**Sub-description:** A Rust-powered local index that pairs perfectly with privacy-first inference like Ollama Cloud, delivering structural knowledge to any agentic tool.

## 3. Tiered Feature Architecture

We will restructure all marketing copy to follow this tiered hierarchy, moving from the most paradigm-shifting capabilities to the baseline enabling technology.

### Tier 1: Epistemic Understanding (The Star)
The foundational differentiator. Not just search, but comprehension.
- **Structural Code Graph:** Meticulous tracing of the DB to map dependencies, call chains, and the "why" and "how".
- **Graph Enrichment:** The 9-stage pipeline that uses Thinking models to continually crystallize and deepen the graph's knowledge.
- **AutoAudit V2:** The system becomes self-aware enough to identify bottlenecks and debt, providing instant hand-off context to tools like Cursor.

### Tier 2: Agentic Leverage (The Polish)
How structural understanding supercharges agent workflows.
- **Role-Aware Context:** The graph intuitively shifts based on the agent's job (e.g., Security Reviewer vs. UI Developer).
- **Atlas Routing:** Smarter retrieval that scopes the inquiry by subsystem before the search even runs.
- **Path Weights:** Elegant signal steering for power users who want sophisticated control over context priority.

### Tier 3: The Engine & Architecture (The Enablers)
The supporting technologies that make the system performant, secure, and viable.
- **Smart Compression:** Intelligently shrinking the payload without losing structural integrity for context windows.
- **Privacy by Design:** Secure endpoints. You own the context. Send it to Ollama Cloud for high-tier privacy inference or keep it local.
- **MCP Native Integration:** Plug-and-play connectivity with Paperclip, Windsurf, Claude Code, and Cursor.
- **Always-Fresh Index:** Incremental Rust rebuilding.

## 4. Retiring Old Tropes
- **"Zero Configuration":** Eliminated. We no longer sell convenience as the primary feature. We sell power.
- **"Runs 100% locally with zero network traffic":** Reframed. We highlight Ollama Cloud endpoints and "Privacy by Design" to allow for off-machine, secure, high-quality reasoning.
- **"Up to 20x compression":** Softened until benchmarked. "Significantly higher signal per token."
