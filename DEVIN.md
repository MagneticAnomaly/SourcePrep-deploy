# DEVIN.md

This file provides guidance to Devin (devin.ai) when working with code in this repository.

## Commit Rules

- **NEVER add `Co-Authored-By` trailers to commit messages.** This
  includes the `Co-Authored-By: Devin <158243242+devin-ai-integration[bot]@users.noreply.github.com>`
  trailer and any similar co-author attribution. Also omit "Generated
  with [Devin]" lines. Commits must be authored solely under the
  committer's identity — no bots, no co-authors. This rule is absolute
  and applies to every commit in this repository.

## Project Overview

This is the SourcePrep repository — a local-first codebase intelligence
platform that builds persistent semantic indexes and serves bounded,
source-cited context to AI coding agents via MCP. See `CLAUDE.md` and
`AGENTS.md` for full project guidance, build commands, and architecture
details. Those files are the canonical reference; this file exists to
ensure Devin-specific rules are explicit.
